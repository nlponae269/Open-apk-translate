# APK Переводчик (Open APK Translate)

Android-приложение, которое переводит интерфейс **любого** APK на русский (или любой из ~59 языков) **прямо на телефоне**, без серверов.

## Как пользоваться
1. Установи `release/OpenApkTranslate-1.0.apk`.
2. Нажми **📦 APK-файл** (поддерживаются `.apk`, `.apks`, `.xapk`) или **📱 Установленное**.
3. Выбери языки (по умолчанию English → Русский) и нажми **🚀 Перевести**.
4. **🗑 Удалить оригинал** → **⬇️ Установить переведённое** (или **💾 Сохранить**).

## Как это работает
- Разбирает `resources.arsc` и переводит строки языка по умолчанию (`string`, `string-array`, `plurals`).
- Перевод: Google ML Kit, работает на устройстве. Языковая модель (~30 МБ) скачивается один раз, после этого перевод идёт офлайн.
- Защита от поломок: не трогает ключи, id, URL, значения настроек; плейсхолдеры `%1$s`, `%d`, `{0}`, теги и переносы строк сохраняются, иначе строка остаётся оригинальной.
- Остальные локали приложения не меняются. Строки, общие со стилями или другими языками, клонируются.
- APK пересобирается (`resources.arsc` без сжатия, выровнен) и подписывается v2 ключом, который создаётся на телефоне.

## Ограничения
- Подпись отличается от оригинала: перед установкой оригинал нужно удалить (данные пропадут), автообновления из Play не придут.
- Не переводится текст, зашитый прямо в layout-файлы или код, и текст, который приходит с сервера.
- Приложения с проверкой подписи / защитой от модификации могут не запуститься.

## Сборка
```
./gradlew :app:assembleRelease
./gradlew :core:test            # тесты ядра
APK_IN=some.apk ./gradlew :core:test --rerun-tasks   # прогон на реальном APK (фейковый перевод "ЖЖ ...")
```
